五、常见坑

坑 1：python 不是内部或外部命令

原因：安装时没勾选 Add to PATH，环境变量没配好。

解决：重装时勾选；或者手动把 Python 安装路径和 Scripts 文件夹加进系统环境变量的 Path。

坑 2：Windows 商店版是”假 python”

Windows 应用商店里的”Python”是一个占位符——命令行敲 python 时它不会运行真正的 Python，而是静默失败（什么都不输出）：

根治方法：开始菜单搜”应用执行别名”→ 关掉 python.exe 和 python3.exe 两个开关 → 重新打开 cmd，python 命令就会命中真正的解释器。

备选：在 VS Code 里用 Python: Select Interpreter 选 D:\anaconda\python.exe，编辑器里运行代码不受影响。

删除变量

和 C 对比：C 里没有”删除变量”这个操作——

  • 栈上的局部变量：函数结束时自动销毁，不用管
  • 堆上的变量（malloc 出来的）：要手动 free() 释放内存

Python 的 del 和 free() 不一样：它只是切断变量名和对象之间的联系（相当于把”标签”从对象上撕下来），对象本身由 Python 的垃圾回收机制自动处理——没人引用它时自动回收内存，不需要手动释放。

一、数字是不可变的（改值 = 重新分配内存）

数字是不可变类型：你无法”修改”一个数字对象本身，改变变量的值，实际上是让变量改指向一个新的对象。

C 里 a = 6 是修改同一块内存里的值：

Python 里 a = 6 是让 a 改指向一个新的对象，旧的 5 对象还留在内存里（直到被垃圾回收）：

用 id() 函数可以验证——它返回对象的内存地址，改值后地址变了，说明确实是新对象：

顺带了解：整数有个小整数缓存机制（-5 ~ 256 常驻内存），所以 a = 5; b = 5 时 a is b 为 True；大数字每次都是新建对象。写代码时不用管，知道有这回事即可。

二、整数没有大小限制

C 的 int 有范围（32 位下约 ±21 亿），溢出会产生各种诡异问题；Python3 的整数没有大小限制，想多大就多大：

刷算法题时完全不用担心溢出，这是 Python 的福利。
