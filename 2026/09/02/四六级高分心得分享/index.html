一篇有意思的博客！

先上成绩单 📜：

不一样的介绍

点进这篇博客的你，最关心的肯定是我如何备考的。

事实是，我没有花多少时间在专门备考上：四级时刷了五六套真题、背了一套作文模板；六级几乎毫无准备，仅仅在考前复习了一下作文模板和做题顺序。

看到这你肯定会暗自腹诽：这人也太凡尔赛了😅，啥也不准备都能考这么高，这篇博客还写个毛线啊！

莫急莫急，话还没说完——我没花时间在刷题和备考上，不代表我没花时间在学英语上。接下来才是我要说的重点：

学英语就像练武功，大部分时间要花在修炼内功——背单词、练听力。当你功力到了，稍微学一点套路招式，便能一通百通，以力破巧~ 🙌

修炼内功

背单词

单词是一切的根基，坚持背就对了。各种碎片时间里少刷点短视频，多背点单词；一个人坚持不下来，就和别人组队背。这里点名表扬「不背单词」App——我一直在用它的组队背单词模式。

这部分内容最重要，却也最没什么可说的，全看执行力💪。所以为了提高你对背单词的重视程度，我要再强调三遍：

听力

听力分为泛听和精听。

泛听：

  • 最好每天泛听半小时及以上，从能跟得上语速的开始，即使很慢也没关系；如果听起来非常模糊，说明这个速度对你来说太快了。
  • 举我自己的例子：大一刚开学时，听四级听力有一半左右是模糊的；到现在，六级听力听着非常清晰，能完全跟上 CNN This Morning 的语速。
  • 材料来源：VOA 慢速英语、四六级真题、VOA 常速英语、油管各种视频、CNN 新闻等等。
  • 主力 App：每日英语听力。另外我关注了一些提供「盲听 / 英文字幕 / 中英文字幕」三种版本视频的 UP 主，比如 B 站「纯正英语原声三十秒」。
  • 关键：要适配自己当前的速度。没太大讲究，选一些感兴趣的话题即可。

精听： 可以以听写的方式，每天听写一分钟四六级真题。我懒得听写😆，用的是偷懒版——在用背单词软件复习单词的时候，顺便听相关例句，先盲听，再看答案。

学习套路

阅读

大学时期我没有学习任何阅读技巧。当然这并不意味着不需要技巧——我没学是因为我在高中的时候，就已经学透了 B 站 UP 主「陶然 free 高考英语」的阅读技巧，并且通过大量训练，有了相当高的做题熟练度。

非常概括地说，这个套路是：先看文章前几段和题目，判断文章大意和题目类型；再根据不同题目类型选择不同解题思路，带着思路去看文章。题目一般有这些类型：

  • 细节题：抓住题目里给出的关键词，带着关键词回头去看具体段落里面的细节。
  • 主旨大意题：需要根据文章主旨来判断答案，可以重点关注开头结尾。
  • 作者观点题：根据文章中作者明确写到、给出态度的句子来判断，不能无中生有。

看到这里，想必你已经对阅读题的答题技巧有了一定的概念。当然，如果你没有理解上面讲的技巧，其实一点关系都没有🤣🤣🤣老实说，我无论是在刷题还是考试的时候，基本都没用上面的技巧——原因也很简单：陶然 UP 主的视频课超级多，阅读技巧也超级多，我高中时还记得，到了大学怎么可能记得住啊！

所以我实际上采用的方法很简单：看文章开头 → 看题目 → 划一些关键词 → 再回头看文章 → 再和题目比对 → 再看文章……没错，就这么简单，就这么轻松~ 😎

我猜，看到这里你肯定又会开始吐槽：这人高中的时候英语好，大学里又坚持背单词，词汇量很高，所以做题很 easy，我又没有这么厉害！他能不能停止他的凡尔赛行为！！！😤😤😤

咳咳，言归正传。关于阅读这块，上面绕来绕去说了一大堆，其实无非就是两个意思：

  1. 技巧是有用且必需的。 当你的词汇量没有那么高的时候，通过学习一些阅读的技巧，并在刷题中不断运用，能很大程度上减轻做题压力；与此同时，不断刷题会让熟练度不断提高，这就为你功力大成后「以一力破万法」打下基础。可惜我大学没有学习任何新技巧，所以无法为你提供推荐，此处需要少侠自行探索~

  2. 当你的词汇量达到一定水平，且已经通过刷题积累了足够的熟练度，恭喜你，轻舟已过万重山，接下来的路想怎么走就怎么走~

注：词汇量具体达到多少才算够呢？这是一个比较主观的问题。我自己考六级的时候，词汇量大概在 6000 出头，而六级大纲词汇量是 5500，所以一个粗略的标准可能就是 5500~6000。当然这并不是定死的，因为还和你的熟练度息息相关。

选词填空

第一轮写这篇博客的时候，我没有把这个板块写进去（其实是忘了试卷上还有这个东西🤡），因为和上面的阅读一样，我也没学习任何技巧，甚至采用的方法都类似：

先看文章开头 → 浏览一遍所有选项 → 再回去看文章 → 遇到不确定的先跳过。等把全篇都看过一遍，能确定七八成的答案，再去思考剩下的不确定答案，基本上两三遍思考就能解决战斗。偶尔遇到不认识的单词，就收藏到我的背单词软件里。

所以还是那句话：技巧应该是有的，但是我没有用，这里也留给少侠自行探索~

翻译

六级的翻译可能是我做的最烂的一部分😵这可能和我平常主要注重输入，没有训练输出有关，所以导致很多明明背过的单词在考场上卡壳想不起来，没能做到准确地表达意思。所以这里我也不好给大家提供什么建议🥴

作文

作为试卷里的主观题，每个人都有自己的写法，所以此处我提供我的写作思路，仅供参考。

我个人认为，作文是一个从模板化到去模板化的过程：从一些固定的套路练起，在不断的练习中逐渐减少套路的占比，最后形成自己的一套风格。四级的时候，我的作文完全按照 B 站 UP 主「我是瑞思拜」提供的模板来写；六级时我尝试去套路化——用了一些模板，也用自己的逻辑。

虽然我四六级的写作翻译分数差不多，但考虑到六级的翻译做的很烂，而且我也没像四级一样考前练习，所以这样的训练思路应该是合理的。

作文还有一个很重要的地方：你的字。 字迹直接影响阅卷老师的第一印象。虽然本人的字写得也还算不错，但除了高中临摹过一些衡水体的字帖，基本没有什么可以分享的东西。

所以为了展示我满满的诚意，本人特地邀请了一位高中同学——她的字写得好、有风格（当然这不是重点，因为我的字也清爽好看）。重点是：有些时候，她的字可以「瞒天过海」——虽然内容写得毫无道理，甚至有明显的、荒谬的逻辑错误，却依然能拿到一个不错的、甚至挺高的分数？？？（此处的三个问号突出强调了作者的不解之意）

一、纸与笔的选择

这方面不同人的习惯其实不太一样，下笔时觉得笔出水顺滑、纸用着流畅即可。我个人偏爱稍微偏粗一点的笔，这样练字时笔锋会比较明显，给练字者的正反馈就比较强。太细的笔容易在纸上断触；并且如果控笔不当，轻微的手抖就会导致写出来的字看起来框架不正、歪七扭八，很打击学习者的自信心。

二、练字过程中需要注意的点

  1. 写的时候可以像我们小时候练字那样，让字母的底端紧贴横线。就我个人而言，大概熟练后，也可以选择「把某条线大致作为一行英文的中轴线」这种练习方式——这种方法让你习惯在不依赖底部横线的前提下，保持所写词句的整齐有序。这样以后在没有横线的纸（比如纯白纸）上写英文，也能保证一定的书写质量。比如下面这个单词，就是用了中轴线：

  1. 写偏圆的字母（比如 a、o、c）时，注意保持圆圈处的饱满度（不要让它看起来太扁）；写偏长的字母（比如 f、y、q）时，注意上下连接处的流畅。

  2. 熟练之后，尝试观察一个单词中间各个字母之间是否有连笔的空间：可以买本字帖看看别人是怎么操作的；也可以自己尝试把一个单词写快，在写快的过程中问问自己——为了提升书写速度，我是否特别想把某两个笔画连起来书写？如果有，可以重点关注连起来是否好看；好看就记住这种连笔方法，下次在类似的单词中也能使用。

  3. 上一条提到连笔，那连笔过程中有没有需要注意的地方？第一，要确保每个字母的主体大小保持一致（不能前一个字母写得很大、下一个写得很小）；第二，牢记连笔只是你书写过程中的点缀，如果你的连笔过于「大」，以至于掩盖了下一个字母的主体部分，那就是喧宾夺主，会影响整体的美观性——这种连笔就不应该被采用。

三、平常的习惯

作为大学生，另外花时间去练字帖性价比其实不高。我们可以选择在备考四六级的同时，在草稿纸上一边练字一边记单词，一举两得；同时也可以在纸上抄写一些例句，来建立单词与单词、句子与句子之间的连接感。

笔者作为英文书写尚佳者，个人的一点经验与书写习惯已悉数列出，希望对大家有一点帮助。最后祝大家练字顺利！

写在最后（绝对正经）

我一直认为，英语是一门很公平的学科——和智商无关，和天赋无关。谁背的单词多，谁听的听力久，谁练的字好看，谁就能考高分。

希望大家都能有所收获！🎉🎉🎉
