我的个人域名网站从0到1

域名、服务器、配置、备案、上线，全流程讲解

引入

我的博客一直托管在 GitHub Pages 上。对于单纯的前端页面来说够用了，但如果想放点需要服务器的东西，比如跑个后端服务、存个数据库，还是需要自己有一台云服务器。于是有了这次建站。

现在网站已经稳定运行了快一个月，拥有了主页和几个子项目，它们都跑在我的云服务器上，前后端都是自己开发的。欢迎大家访问 https://tsx.world/

省流版总结：技术部分用agent半天就能搞定，真正占时间的是两个备案。所以顺序很重要：先提交备案，再搞技术，让等待时间和你的准备工作并行。

接下来是详细介绍。

一、买域名

域名购买的渠道有很多，我选择在阿里云购买，因为可以和我的服务器在一起管理，域名注册等服务阿里云也会提供，比较省心。一般.com和.cn的后缀名比较贵，其他的后缀名比较便宜，所以我选择了 tsx.world ，我的名字缩写加上便宜且有意义的后缀名。第一年仅需23元，第二年104。

买完第一件事是实名认证。国内注册的域名必须实名，不认证域名会被暂停解析。在阿里云控制台下图界面，按流程进行认证，一般一两天就通过了。

二、买服务器

阿里云和腾讯云的优惠力度都很大，一台轻量服务器第一年仅需一百元左右，甚至都不用。这方面网上的教程非常多，这里不再赘述。我使用了阿里云的大学生300元无门槛券，免费购买了原价270的2核2G的轻量应用服务器

三、域名解析

域名解析，就是把域名翻译成 IP 地址。

服务器在网络里的真实地址是一串数字（比如 118.31.60.18），域名只是给它起的一个好记的名字。浏览器里输入 tsx.world 的时候，它并不知道要连哪台机器，会先去问 DNS 服务器”这个域名对应哪个 IP”，拿到答案才能连上你的服务器。

所以买完域名，还要做一步解析：告诉 DNS”tsx.world 指向我的服务器 IP”。不做这一步，域名就是一个没人认识的空名字。

在阿里云云解析 DNS 里加两条 A 记录：

记录类型 主机记录 记录值
A @ 服务器公网 IP
A www 服务器公网 IP

@ 代表裸域名（tsx.world），www 代表 www.tsx.world。两条都加上，两个地址就都能访问。

四、服务器初始配置

4.1 可选：装个 SSH 客户端

服务器上执行的命令，都要先通过 SSH 远程登录到服务器，在它的终端里敲。Windows 自带的 PowerShell 也能连（直接输 ssh root@服务器IP 就行），但每次都要敲一遍 IP，日常维护可以装个专门的 SSH 客户端，能保存连接、双击即连。我用的是 Xshell。当然也可以直接让agent来帮你登录。

下载安装：搜「Xshell」进官网 → 选「家庭/学校免费版」→ 填个邮箱就能下载，安装一路下一步。

装好后新建连接：

  1. 点左上角「新建」，名称随便起（比如 我的服务器）
  2. 在「连接」页填三项：
    • 协议：SSH
    • 主机：你的服务器公网 IP
    • 端口号：22
  3. 点「连接」——第一次会弹「SSH 安全警告」，选「接受并保存」
  4. 输入用户名 root 和密码，回车，就登进服务器了

五、HTTPS：一条命令的事

HTTPS 就是给网站的通信加密。

HTTP 协议下，浏览器和服务器之间传输的所有数据都是明文——访客填的表单、输入的密码，在网络上经过的任何节点都能看到、能篡改。HTTPS 会在两端建立一条加密通道，数据在传输途中是加密的，中途被截获也读不出内容。另外，现在浏览器对 HTTP 网站会直接在地址栏标「不安全」，所以 HTTPS 已经是网站的标配。

加密通信需要一张「证书」来证明这个服务器确实是它声称的那个域名。证书以前要花钱买，现在有 Let’s Encrypt 提供免费的，而且能自动续期。我们只需要执行下列命令：

六、ICP 备案

ICP 备案是什么：ICP 的全称是 Internet Content Provider，直译”网络内容提供商”。国内规定，网站必须向工信部登记”这个网站是谁办的、放在哪台服务器上、叫什么名字”，通过后发一个备案号。实际作用是硬性的：国内服务器上，没备案的域名不能用 80/443 端口对外提供服务——不备案，网站直接访问不了，没有绕过的办法。

网站备案分成 ICP 备案和公安备案：ICP 备案归工信部管，相当于”接入许可”；公安备案归公安部管，是”网络安全责任”登记，网站上线后 30 天内办理，办理时要签一份网络安全责任书。所以顺序是：先办 ICP 备案，再办公安备案，ICP备案通过后网站就能上线。

我实际经历的流程和时间线：

整个过程约 9 天，其中大部分是管局审核的排队时间。

管局是什么：管局是各省的通信管理局，工信部在各省的分支机构。备案的最终审核单位就是它。在阿里云提交材料后，阿里云先做初审，再转交管局排队审核，等待时间主要耗在管局这一环，各省管局的处理速度不太一样。

https://beian.miit.gov.cn/ 是工信部的备案信息查询系统：任何人都可以在上面输入域名，查到网站的备案号、主办单位、备案时间。备案号必须链接到它，相当于留一个”验证入口”——访客点一下就能核实这个网站确实备过案，而不是随便写的一串编号。

公安备案不像之前ICP备案，没有阿里云帮你推进流程，需要自己全程跟进。

平台是全国互联网安全管理服务平台 https://beian.mps.gov.cn要自己注册账号填写。

注意：备案时使用的主体信息中，地址不是户籍地址，而是现居地址！

九、一台服务器跑多个项目

建站最初的时候，我只放了个主页，后来陆续加了子项目，都是在同一台服务器上通过 Nginx 路径分流。

Nginx 是一个”Web 服务器”软件，职责是接收访客的请求，把对应的内容返回过去。它主要干两件事：

  • 访客要的是 HTML、图片这类静态文件 → 直接从服务器磁盘上读出来返回
  • 访客要的是 API 数据（需要后端程序现场处理的）→ 把请求转交给后端程序

多项目共存靠的就是它的路径分流能力：同一个域名下，访问 /pingpong/ 走乒乓球项目，访问 /lostfound/ 走失物招领，互不干扰：

配置里的 proxy_pass 就是反向代理：后端 Go 程序只监听本机地址（127.0.0.1:8081，外网根本访问不到），Nginx 对外接收请求后替访客转交给后端，再把结果带回来。相当于后端程序躲在 Nginx 后面，由 Nginx 统一对外接待——后端不用直接暴露到公网，更安全，多个服务也能共用一个域名。

每个后端服务用 systemd 托管。systemd 是 Linux 自带的”服务管家”：程序如果直接在终端里跑，窗口一关就停了；交给 systemd 托管后，程序后台常驻、开机自动启动、崩溃了自动拉起。只需要写一个配置文件告诉它”启动哪个程序”：

systemctl 是跟这个管家打交道的命令：enable 设为开机自启，--now 表示顺便立刻启动。平时看运行状态用 systemctl status myapp，改完代码重启用 systemctl restart myapp。
